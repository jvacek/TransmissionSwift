Download TransmissionSwift

Free · macOS 26+ · ~4 MB. Pick a build:

Download universal (Apple silicon + Intel) Download Apple silicon only

The universal build runs on any Mac and is the safe choice. The Apple-silicon-only build is smaller and fine on any M-series Mac. Both self-update via Sparkle.

How to open it

Releases are currently unsigned, so macOS Gatekeeper blocks the first launch. It is a one-time step per install:

  1. Unzip the download and move TransmissionSwift.app to your Applications folder (or run it straight from Downloads).
  2. Open the app. macOS refuses it, so choose Done, not Move to Trash.
  3. Open System Settings → Privacy & Security, scroll to the Security section and click Open Anyway (the button stays for about an hour).
  4. Confirm with your password and open the app again.

The same steps are in Apple's support article and the project README. Once it opens, the remote setup guide shows how to connect it to your daemon.
