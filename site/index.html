TransmissionSwift — a native Transmission remote for macOS

TransmissionSwift is a free, native SwiftUI macOS client for a remote Transmission BitTorrent daemon. Connect over RPC and manage your torrents from your Mac — no browser, no web UI. It is a modern alternative to Transmission Remote GUI (transgui).

Download for macOS View on GitHub

Features

  • Manage active torrents: start/pause, delete (with or without data), verify, update tracker, set priority and unwanted files, change download location
  • Add new torrents from .torrent files (drag & drop or handler) or magnet links
  • Change server settings, including slow mode, networking and seeding config
  • Combine filters in the sidebar, manage torrent labels and colour coding
  • Path mapping via custom URI patterns and ready-made presets (Cyberduck, Finder, default app, Swizzin)
  • Self-updating via Sparkle

Requirements

macOS 26 or later. The app is a ~4 MB universal binary (Apple silicon and Intel) written in Swift and SwiftUI.

Installing an unsigned build

Releases are currently unsigned, so macOS Gatekeeper will block the first launch. Open the app once, choose Done rather than Move to Trash, then open System Settings → Privacy & Security and click Open Anyway. The README walks through it with screenshots.
