TransmissionSwift / Comparison

A native Transmission remote for macOS

TransmissionSwift is a free, native SwiftUI client for a remote Transmission BitTorrent daemon. If you have been using Transmission Remote GUI (transgui), this page compares the two: the same daemon, with a modern Mac app in front of it.

Download for macOS How to connect

Why switch from transgui

  • It is a real Mac app. TransmissionSwift is written in Swift and SwiftUI, so it uses native macOS controls, menus, keyboard shortcuts, Dark Mode and the system look instead of a ported widget toolkit.
  • Native on Apple Silicon. A ~4 MB universal binary runs natively on M-series and Intel Macs. No Rosetta translation.
  • Same daemon, nothing to change. Both speak the classic Transmission RPC API, so you point TransmissionSwift at the daemon you already run. There is no server-side migration.
  • Automation transgui never had. App Intents let you add torrents, read stats and control the daemon from Shortcuts.app, Spotlight and Siri.
  • Organised torrents. Combine sidebar filters and tag torrents with colour-coded labels.
  • Up to date. Sparkle keeps the app updated, and the project is actively developed.

How to migrate from transgui

  1. Download the latest TransmissionSwift release and open it from your Downloads folder. Unsigned builds need a one-time Gatekeeper approval; see the FAQ.
  2. Add a server using the same host, port, path and credentials you use in transgui. TransmissionSwift stores passwords in the macOS Keychain.
  3. Connect. Your existing torrents appear immediately, because the daemon, not the client, holds the session.
  4. Optionally set up path mapping so you can open downloaded files in Cyberduck, Finder or another app straight from the torrent list.

Still on the same daemon. Nothing about your Transmission setup changes. If you ever switch back, transgui will find everything exactly where you left it.
